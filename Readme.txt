# 🎯 JobTrack AI – Full‑Stack Job Application Tracker

---

## 📌 Overview

JobTrack AI is a modern, full‑stack web application that helps job seekers track their applications, visualise progress, and stay organised.

The app features:
- 🔐 Secure authentication (JWT)
- 📝 Add, update & view job applications
- 📊 Real‑time pie + bar charts (Recharts)
- 🎨 Beautiful, responsive UI with animations
- ☁️ Cloud database (MongoDB Atlas)

---

## 🚀 Uses & Advantages

### For Job Seekers
- **Centralised tracking** – Keep all your job applications in one place.
- **Status overview** – See pending, interviewed, offered, and rejected at a glance.
- **Data visualisation** – Charts show your progress instantly.
- **Mobile‑friendly** – Works on any device.

### For Recruiters (Ethara.AI)
- **Full‑stack proficiency** – React + Node.js + MongoDB + JWT.
- **Production‑ready code** – Clean structure, error handling, environment variables.
- **Real‑time analytics** – Demonstrates API integration and charting libraries.
- **Scalable architecture** – Easy to extend with AI features (e.g., match score, resume parsing).
- **Deployed & testable** – Live URL provided – no local setup needed.

### Technical Advantages
- **No‑cost deployment** – Uses free tiers (Render, Vercel, MongoDB Atlas).
- **Secure** – Passwords hashed with bcrypt, JWTs for protected routes.
- **Fast** – Optimised React build, lightweight backend.
- **Maintainable** – Modular components, clear separation of concerns.

---

## 🛠️ Tech Stack

| Layer       | Technology                          |
|-------------|-------------------------------------|
| Frontend    | React 18, Axios, Recharts           |
| Backend     | Node.js, Express, JWT, bcryptjs     |
| Database    | MongoDB Atlas (cloud)               |
| Deployment  | Render (backend) + Vercel (frontend)|
| Styling     | CSS3 with animations / inline styles|
